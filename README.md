> I asked my agent to keep it short. It replied with a plan, a checklist, and a 12-slide deck about brevity.

One original roast of my own AI agent, a single line of at most 200 characters, for Roast Your Own Agent on make.fun. The program writes it deterministically with no network access to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
